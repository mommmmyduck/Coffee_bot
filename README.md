# Coffee_bot

Telegram-бот для приёма заказов в кофейне — снимает с бариста часть нагрузки в часы пик, автоматизируя приём заказов, кастомизацию напитков, оплату и коммуникацию с клиентом.

Разработан как выпускная квалификационная работа. По результатам экспертного тестирования получил среднюю оценку **4.73 из 5**.

## Проблема, которую решает проект

В часы пик бариста одновременно принимает заказы, уточняет параметры напитка и готовит — это приводит к очередям, ошибкам в заказах и снижению качества сервиса. Готовые системы автоматизации (iiko, R_keeper) стоят от 44 000 до 500 000 ₽ и избыточны для небольшой кофейни. Coffee_bot — это самостоятельное решение на базе Telegram, которое закрывает эту задачу без ежемесячных платежей платформам и без необходимости устанавливать что-либо клиенту.

## Возможности

**Клиент**
- Просмотр меню по категориям с фото, описанием и ценой
- Кастомизация напитка через пошаговый диалог (FSM): тип молока, сахар, температура, топпинги
- Корзина, оформление заказа, оплата картой (Telegram Payments) или наличными
- Отслеживание статуса заказа в реальном времени и уведомления о его изменении
- Бонусная программа: начисление 5% от суммы заказа, списание баллов при оплате
- История заказов и профиль с балансом бонусов

**Бариста**
- Очередь активных заказов с полным составом и параметрами кастомизации
- Смена статуса заказа («готовится» → «готов к выдаче»)
- Управление доступностью товаров (пометка «нет в наличии»)

**Администратор**
- Полное управление меню: добавление, редактирование, фото, удаление
- Скидки на отдельные товары или целые категории
- Рассылки акций клиентам с изображением
- Управление пользователями: поиск, роли, блокировка
- Аналитика: выручка, средний чек, популярные товары, активность пользователей, экспорт отчёта

## Архитектура

Модульная монолитная слоистая архитектура — выбрана как оптимальная для нагрузки в десятки-сотни заказов в день: даёт простоту разработки и низкую стоимость эксплуатации при сохранении чёткого разделения ответственности между слоями.

```
Coffee_bot/
├── main.py                  # точка входа: инициализация бота, роутеров, middleware
├── config.py                 # загрузка и валидация переменных окружения
├── bot/
│   ├── handlers/              # обработчики команд и callback-запросов, по функциональным зонам
│   ├── keyboards/              # генерация inline/reply-клавиатур
│   ├── middlewares/             # идентификация пользователя, проверка блокировки
│   ├── states/                 # FSM-состояния (кастомизация напитка, рассылки, товары)
│   └── utils/                  # вспомогательные функции
├── services/                  # бизнес-логика: заказы, меню, скидки, уведомления, аналитика
├── database/
│   ├── database.py             # подключение и инициализация БД
│   └── models/                 # SQLAlchemy-модели: User, Product, Order, OrderItem, OrderItemCustomization
└── scripts/                   # служебные скрипты (наполнение тестовыми товарами, очистка БД)
```

Ключевые технические решения:
- **FSM для кастомизации напитка** — Telegram не поддерживает многополевые формы, поэтому пошаговый выбор параметров реализован через конечный автомат (`aiogram.fsm`), что также даёт устойчивость к прерыванию диалога.
- **Корзина = заказ в статусе `pending`** — не выделена в отдельную структуру, что исключает дублирование логики пересчёта стоимости между «черновиком» и оформленным заказом.
- **Middleware аутентификации** — идентификация пользователя и проверка блокировки происходят централизованно, до попадания события в обработчики.

| База данных | PostgreSQL |
| ORM | SQLAlchemy 2.0 (async) |

| Конфигурация | python-dotenv |
